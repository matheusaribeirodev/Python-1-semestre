# IMC.PY
📊 Projeto Calculadora de IMC

Uma aplicação simples desenvolvida para calcular o Índice de Massa Corporal (IMC) de um usuário a partir do peso e altura informados. O projeto tem como objetivo praticar lógica de programação, entrada de dados e condicionais.

🚀 Funcionalidades
Entrada de peso e altura
Cálculo automático do IMC
Classificação do resultado:
Abaixo do peso
Peso normal
Sobrepeso
Obesidade
Interface simples e fácil de utilizar
